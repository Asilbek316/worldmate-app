# WorldMate Global V7.1 — GitHub Pages

GitHub Pages edition of WorldMate.

## Publish
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

This edition is a static frontend. It does not run the Python/SQLite backend on GitHub Pages.

Included client-side features:
- English / Russian / Uzbek UI
- OpenStreetMap + Leaflet
- Global geocoding via Open-Meteo
- Browser GPS
- Weather via Open-Meteo
- Currency via Frankfurter
- Browser speech input/output where supported
- Camera preview
- Itinerary generator
- Local browser profile
- Responsive design

Real cloud login, SMS/email verification, persistent users, admin database, OAuth, hotel/flight booking, production OCR/translation and other server features require a backend/provider.
